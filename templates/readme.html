这是什么

把机场订阅（V2 / Clash / sing-box / 分享链接）按指定模板展开，生成可直接交给 sing-box 使用的 config.json。也支持直接调用 POST /config 接口。

快速上手

  1. 在「生成器」页填一条或多条订阅 URL；
  2. 按需设置 tag、prefix、User-Agent、emoji，选择模板；
  3. 点「生成 config.json」下载完整配置，或点「生成订阅 JSON」下载请求体 providers.json。

字段说明

  • 订阅 URL：机场订阅链接；也支持 vmess:// 等分享链接、base64、Clash YAML、sing-box JSON。
  • tag：订阅标识 / 分组键，模板里可用 {tag} 引用该订阅的节点。留空会自动补 tag_1、tag_2…，且必须唯一。
  • prefix：节点名前缀，保留空格；最终顺序为 prefix + emoji + 节点名。
  • User-Agent：拉取订阅时使用的 UA。下拉可选常见客户端，也可直接输入自定义值（如 clash-verge/v2.4.2）。
  • emoji / 间隔：是否按国别加国旗；可选 emoji 与节点名之间「空格 / 无空格」。
  • 模板：config_template/ 下按文件名排序的模板，默认 default。
  • 自定义模板 URL：填了就优先于上方下拉，服务端会去 GET 这个地址。
  • 排除的协议：逗号分隔，默认 ssr，例如 ssr,hy2。

两个按钮

  • 生成订阅 JSON：只把当前表单拼成请求 JSON（providers.json）并下载，不访问接口。
  • 生成 config.json：调用 POST /config，成功后下载完整 sing-box 配置。

模板的四种来源

  • 留空 / 不写：使用 config_template/default.json（固定默认模板）；
  • 文件名：如 sb-config-1.12，读取 config_template/sb-config-1.12.json；
  • 远程 URL：如 https://example.com/tpl.json；
  • 内联对象：直接在请求 JSON 里写 "config_template": { "outbounds": [...] }。

直接调用接口

curl -s http://127.0.0.1:5000/config \
  -H 'Content-Type: application/json' \
  -d '{
        "subscribes": [
          {"url": "https://a.com/sub?token=AAA", "tag": "airportA", "prefix": "A-"}
        ],
        "config_template": "default",
        "exclude_protocol": "ssr"
      }' \
  -o config.json

请求字段、错误码、file:// 本地订阅、LOCAL_DATA_DIR 等见 docs/api.md。

排错

  • 生成失败时，页面右下角会弹出错误；更完整的信息在「日志」页。
  • 日志是进程内环形缓冲（最近 200 条），进程重启后会清空；多进程部署时各进程各有一份。
  • 常见原因：订阅链接无法访问、UA 不匹配、模板不存在、订阅里没有可解析的节点。

安全提示

  • 接口无鉴权，建议只在内网 / 本机使用，或自行加反向代理与认证。
  • 本机模板只允许读取 config_template/ 目录；本地订阅文件受 LOCAL_DATA_DIR 限制。
